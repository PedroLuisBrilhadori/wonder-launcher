# Wonder Launcher — WonderKing Classic

Jogue WonderKing no servidor da comunidade **Wonder Classic**.

## Como instalar

1. **Baixe o launcher**: pegue o `WonderLauncher.zip` na página de
   [Downloads](../../releases) e extraia.
2. **Você precisa do jogo original** (cliente WonderKing US 2011 — a pasta com
   `Load.exe`, `value/`, `sound/`). Nós **não distribuímos o jogo**: cada
   jogador usa a própria cópia.
3. Copie os 2 arquivos extraídos (`WonderLauncher.exe` e `info.ini`) para
   dentro da pasta do jogo.
4. Abra o `WonderLauncher.exe`, espere o **PRONTO PARA JOGAR** e clique em PLAY.

Na primeira execução o launcher instala sozinho as melhorias de imagem e
sincronização — não é preciso copiar mais nada.

## Dúvidas comuns

**O Windows ou o antivírus reclamou do launcher.**
O projeto não tem assinatura digital paga (é caro), então o Windows mostra um
aviso amarelo. Clique em **"Mais informações" → "Executar assim mesmo"**. Para
conferir a integridade do download, o código SHA-256 de cada versão está
escrito na própria página de download.

**Apareceu "faltam arquivos do jogo".**
O launcher precisa rodar **dentro** da pasta do cliente original (a que tem o
`Load.exe`), não numa pasta separada.

**Como crio minha conta?**
Botão **"Criar Conta"** no próprio launcher (só funciona com o servidor online).

**De onde vem esse servidor?**
É um servidor próprio da comunidade (emulador feito pelo projeto). Não temos
relação com os detentores originais do jogo — distribuímos apenas o nosso
próprio código, e o jogo em si cada jogador usa a própria cópia.
